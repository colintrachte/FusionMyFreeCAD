# FreeCAD Documentation & Manual

The official FreeCAD documentation and manual are maintained online and updated with each release:

- **FreeCAD Official Wiki & Manual**: [https://wiki.freecad.org/Manual:Introduction](https://wiki.freecad.org/Manual:Introduction)
- **FreeCAD Documentation Portal**: [https://wiki.freecad.org/Main_Page](https://wiki.freecad.org/Main_Page)
- **FreeCAD Source & Releases**: [https://github.com/FreeCAD/FreeCAD](https://github.com/FreeCAD/FreeCAD)

To keep the repository lightweight and fast to clone, large binary manuals are not distributed inside the repository.
